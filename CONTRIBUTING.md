# Contributing Guidelines

Thank you for your interest in contributing to **Audira YT Monitor**!

## How to Contribute

1. **Fork the Repository**: Create your own feature branch from `main`.
2. **Code Standards**:
   - Frontend: Follow Next.js App Router conventions and Vibrant Neo-Brutalism design tokens (`border-4 border-black`, `shadow-[4px_4px_0_0_#000]`).
   - Backend: Follow FastAPI and SQLAlchemy ORM type hints and async standard patterns.
3. **Commit Messages**: Write clear, descriptive commit messages.
4. **Pull Requests**: Open a Pull Request against the `main` branch with a summary of changes and verification testing.
